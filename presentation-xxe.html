Comprendre XXE en 5 minutes

Quand un document XML
fait lire autre chose

XXE signifie XML External Entity : une injection d’entité externe XML.

<message>Bonjour</message>

Le XML organise des données avec des balises. Son lecteur, le « parseur », peut aussi résoudre des références vers des fichiers ou des adresses web. Une configuration dangereuse permet d’abuser de cette fonction.

01 / XXE classique

Le contenu du fichier apparaît
dans la réponse

« À la place de ce texte, lis ce fichier du serveur. »

  1. Une personne envoie un XML avec une référence externe.
  2. Le parseur vulnérable lit le fichier référencé.
  3. L’application renvoie son contenu dans la réponse.

Exemple fictif : le fichier secret.txt contient CODE-42. La réponse affiche CODE-42 : la fuite est directement visible.

02 / XXE aveugle

Un rappel révèle
l’activité du serveur

« Pour lire ce document, contacte cette adresse. »

  1. Le XML référence un serveur de rappel contrôlé par le testeur.
  2. Le parseur vulnérable envoie une requête vers ce serveur.
  3. Le testeur observe ce contact, même si la réponse ne révèle rien.

C’est comme une sonnette : le rappel indique que quelqu’un est passé. Un contact sortant ne prouve pas, à lui seul, un vol de données.

La différence à retenir

Où voit-on la preuve ?

XXE classiqueXXE aveugle par rappel
Dans la réponse de l’application.Sur le serveur de rappel.
On voit le contenu récupéré.On observe une requête sortante.

La cause reste la même : le parseur accepte des références externes provenant d’un XML non fiable.

Une réponse vide ou l’absence de rappel ne suffit pas à prouver qu’une application est sûre.

Protection

Limiter ce que le parseur
peut aller chercher

  1. Désactiver la résolution des entités externes.
  2. Désactiver les DTD si elles sont inutiles.
  3. Vérifier la protection dans un laboratoire autorisé.

Une DTD peut définir les entités d’un document XML. Les réglages exacts dépendent du parseur utilisé.

À retenir : classique = preuve dans la réponse.
Aveugle = preuve observée par un autre canal.
